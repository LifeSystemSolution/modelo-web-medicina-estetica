# Modelo web · Medicina estética

**Ver demo:** https://lifesystemsolution.github.io/modelo-web-medicina-estetica/

Demo de una web de una sola página para una clínica de medicina estética, con tres propuestas de diseño en un mismo archivo. Diseñada primero para celular.

| Opción | Estilo |
|---|---|
| A · Editorial de autora | Negro, oro champán y marfil, con títulos con serifa |
| B · Calma clínica | Marfil, arena y café, con bordes suaves |
| C · Guía por zonas | Tarjetas en rejilla y títulos condensados; los tratamientos se filtran por zona del rostro |

El selector de la parte superior cambia entre opciones (`#opcion-a`, `#opcion-b`, `#opcion-c`).

## Qué incluye

- 9 tratamientos agrupados en 4 categorías, con filtros
- Sección destacada de la especialista
- Botón de WhatsApp fijo, con un mensaje distinto por tratamiento
- Cómo funciona, preguntas frecuentes, ubicación y aviso médico
- Datos estructurados `MedicalClinic` y meta descripción para Google

## Uso

Es una página estática, sin dependencias ni compilación. Abre `index.html` en el navegador o publícala en GitHub Pages.
